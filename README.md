# Makeup Studio & Beauty Salon

A modern beauty parlour and makeup studio web application built with [Vite](https://vite.dev/).

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
